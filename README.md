# 🌹 Invitación 15 Años — Luciana & Silvana

Invitación virtual de 15 años con diseño glassmorphism y animaciones elegantes.

## Tecnologías
- HTML5 + CSS3
- Tailwind CSS (CDN)
- Express.js (servidor)
- Google Fonts · FontAwesome

## Desarrollo local

```bash
npm install
npm start
```

Visita `http://localhost:3000`

## Despliegue en Railway

Este proyecto está listo para desplegarse en [Railway](https://railway.app):

1. Crea un nuevo proyecto en Railway
2. Conecta este repositorio de GitHub
3. Railway detectará automáticamente la configuración y desplegará el sitio
